**PoliAule** is a website that allows to find available classrooms around Politecnico di Milano.

It offers a simple and intuitive UI that makes looking for free classrooms easy and fast, especially compared to the official tools provided by Politecnico di Milano.

PoliAule makes use of an internal API from PoliMaps, fetches up-to-date data for the next 7 days every night and provides the cached data to users to avoid overloading the official API endpoint.
