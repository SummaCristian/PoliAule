## Search
Inspired by Spotlight, the new Search sorts its results into sections and shows the most promising one at the top, in the new "Top Hit" section.

Professors have their own page inside Search, with all their classes and exams grouped by course. Courses can also group several occupations together in an expandable row, so the list is easier to scan.

On desktop the whole UI works with the keyboard: arrow keys move the selection, Enter opens it, and Esc closes Search.

## Performance
Getting ready for the stable launch of PoliAule 2, I've started working on performance. This update tackles the two biggest sources of lag: the map and the navigation transition.

### Map
The Mapbox map now loads entirely in a background thread, leaving the main thread to the UI and your interactions. The first load may take slightly longer, but it's a worthy trade for a smoother experience overall.

The details page shows the same map as the Campus tab, and moving and resizing it during each transition was another big hit. Now that only happens after the transition ends, or before it only when going back to the Campus tab, so the transition has the main thread to itself.

### Navigation transition
The zoom transition into a classroom is still there, smoother than ever. It has been reworked (again!) to hand as much as possible to the browser's compositor, which runs outside the main thread and is usually more optimised than anything possible in JavaScript.

Tested on all major browser engines: Chrome and Firefox on desktop, Safari and Chrome on mobile. On an automated test bench, a 2019 Android 12 phone running Chrome averaged around 55 fps out of 60, while Safari on iOS 27 hits around 115 fps out of 120.

## Thumbnails
A new endpoint serves lower-resolution versions of the classroom pictures, generated by the same monthly job that fetches them. The UI uses them where pictures are small, like the grid cards and search results, and keeps the full resolution for the large header in the details page. This made a big difference to the app's overall performance.

## Transfer
PoliAule has no accounts and no cloud sync, so a new feature in Settings lets you move your settings and favourites from one device to another yourself.

They're encoded in a link: open it and PoliAule asks whether you want to import them. You can share the link directly or scan the QR code PoliAule generates for you.
