This release brings a few UI improvements, some under-the-hood changes to the way data is presented, and a complete mapping of all the remaining campuses of PoliMi.

## Data freshness
An indicator in the top right corner blinks green if the data is fresh, yellow if there is data but it's older than 24 hours, and red if something is wrong with it.

## Popovers
This new UI component will be used throughout the whole website to show additional information whenever it's needed.
